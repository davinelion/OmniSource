01 About

BlueWallet is a free and open-source Bitcoin wallet focused on simplicity and power. Create standard on-chain wallets, watch-only wallets with full PSBT and hardware-wallet support, and Lightning wallets backed by the built-in LNDHUB or your own node — with fee control, multisig (Vault) and Tor connectivity.

Release notes
BlueWallet 8.0.1 | BlueWallet_8.0.1_1784575843

### New Features

iOS 26 Liquid Glass design
Import Unchained JSON as a multisig cosigner
Support BC-UR v2 air-gap scanning for hardware wallets (OneKey, Keystone)
Option to redact push notification content
Arkade Lightning push notifications
Enable RBF for single-sig watch-only wallets (HD Bech32)
Human-readable data on transaction status screen
19 new languages, including Filipino, Armenian, Akan, and Sesotho

### Improvements

Renewed Settings UI
Better green success color contrast
Removed GroundControl server URL option from notification settings
Faster transaction fetching for HD wallets
Replaced crypto-js with modern @noble crypto libraries

### Fixes

Startup crash
Amount input lag in RBF custom fee input
Text size on main app views and clipped wallet balance in carousel
QR codes no longer have rounded corners
Signed transaction hex screen stays scrollable
Arkade LNURL payment result now persists
Floating button no longer overlaps the transaction list
Various modal and navigation UX polish

Under the hood: dependency updates, TypeScript coverage improvements, CI and translation tooling fixes.
