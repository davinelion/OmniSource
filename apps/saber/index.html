01 About

Saber is a free and open-source handwritten notes app built with Flutter. Write with your finger or Apple Pencil as if on paper, organize notes into folders, keep them private with encryption, and sync across devices using its optional Nextcloud-based sync — no vendor lock-in.

Upstream publishes no screenshots for this app, and OmniSource does not invent them.

## Changelog

- Improved the design of the login flow, making better use of space on landscape/desktop screens.
- Tweaked scrolling friction in the editor to make it less slippery. #1785
- Fixed handling of accounts with unlimited storage quota. #1796 
- Fixed folders not being sorted in the browse page. #1809 
- Fixed parts of the app using a hardcoded Ubuntu font. eafaf264b19a35cbf8e8831daa4118e1446fe16d and https://github.com/ubuntu/yaru.dart/pull/1075.
- Fixed non-Latin language fonts and inconsistent UI elements in Flathub screenshots.
- Improved build system... Now fewer custom patches are needed for various stores. Enabled the `--enforce-lockfile` flag for F-Droid for more reproducible builds. #1799 
- Fixed Android 16KB page size support by forcing a newer NDK version. 87fcb037ba8792cd24ef3af66335007854dbdabc
- Continued code cleanup, refactoring, testing, and small UX improvements.
- Various fixes from [Flutter 3.47.2](https://github.com/flutter/flutter/blob/stable/CHANGELOG.md#3472)
- Translations:

  - i18n: Various small tweaks to fix Weblate lints (e.g. adding a trailing colon to match the English equivalent)
