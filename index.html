INSTALLATION GUIDE

Up and running in three steps

OmniSource works with every major sideloading client. No computer required for the one-tap clients.

1

Pick a client

SideStore for most people: free, and it refreshes apps on the phone after a one-time setup. AltStore if you want the reference client or you are in the EU. FlareStore if you would rather not touch a computer or re-sign weekly. Feather on a jailbroken or TrollStore device.

2

Add the source

One tap for AltStore, SideStore, FlareStore and Feather — or copy the source URL and paste it into ESign, Ksign or LiveContainer.

3

Install any app

Browse the catalog, tap Get. Updates flow in automatically on every six-hour sync.

BUILT ON TRUST

Current by design.

OmniSource is transparent about where every build comes from and keeps the catalog healthy without manual busywork.

01

Curated upstreams

Releases resolve from official GitHub projects or each developer’s own feed — never random re-uploads.

02

Automated updates

The pipeline syncs every six hours, publishes per-app feeds and RSS, and keeps version history for rollbacks.

03

Verified daily

Every download is probed; broken links raise an issue automatically. Origin, status and requirements stay visible.
